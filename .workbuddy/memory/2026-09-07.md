## education-platform 重构审计（只读勘察，未改代码）

产出：`docs/REFACTORING_AUDIT.md`（完整审计 + P0–P4 路线图）。

项目定位：用户最初为「学 JDK21、脱离 JDK8」而建，现目标升级为「JDK21 工程基线 + 高版本框架适配 + LangChain4j 充分实践」。

### 核心发现（已核验，可直接引用）

1. **JDK 版本自相矛盾**：根 pom `maven.compiler.release=23`（infra/pom.xml 还硬编码 source/target 23），但 Dockerfile 与 GitHub Actions 都是 JDK 21 → 构建产物必然 `UnsupportedClassVersionError`。JDK 23 已于 2025-03-18 EOL（非 LTS）。JDK 21 LTS 支持至 2028-09-30。**本机未安装 JDK 21**（现有 8/11/23.0.2/24/25）。
2. **DDD 骨架空转**：domain 19 类 / application 8 类 / infra 30 类 / common 89 类 / education-back 231 类。仅 `dict` 领域完整走通，231 个业务类无一行引用 domain/application。建议方案 A（务实四层拆分），不做纯 DDD。
3. **LangChain4j 处于第 1 层**：0.36.2（现任 1.17.2，跨 1.0 breaking：`ChatLanguageModel.generate()` → `ChatModel.chat()`）。仅裸调用 + 正则抠 ID + 兜底硬编码 `List.of(1,2,3)`。未用 AiServices / ChatMemory / RAG / @Tool / Streaming / 结构化输出。会话用无界 ConcurrentHashMap 存内存。
4. **Ollama 模型名虚构**：`gemini-3-flash-preview:cloud` 在 Ollama 官方模型库不存在，README 与 start-ai.sh 同步错误。
5. **安全**：OSS AK/SK、Cloudflare R2 Secret、ES 密码明文在 application.yml 且已提交；`ddl-auto: update` + `active: prod`；actuator 全量暴露；`logRequests/logResponses(true)` 泄露隐私。
6. **死代码/错配**：springfox 3.0.0（0 引用、Boot3 不兼容）；`IPLimitFilter` 实现 WebFlux `GlobalFilter` 但应用是 Servlet，永不执行；ShardingSphere 4.1.1(2019) + Seata 1.5.2 零使用；3 个 lombok-1.8.36.jar 提交进 src/main/resources/lib。
7. **语言级别**：record / var / sealed / Optional / 虚拟线程显式用法全为 0；@Data 56 个；java.util.Date 14 文件；@Autowired 36 类 vs 构造器注入 18 类；参数校验注解 0 处（却有 5 个全局异常处理类）；System.out 53 处；测试仅 1 个类 + skipTests=true。
8. **LOG_PATH_IS_UNDEFINED 成因**：logback-spring.xml 的 `<springProperty source="log.filepath">` 无对应 yml 配置，仓库根已堆积 14 个 log 文件。
